## Where we can use Singleton Design Pattern:

We can use singleton design pattern when we need only one object to get instantiate of any service or application. - And multiple instances banane se memory bhi affect hoti h.

1. Logging System - we dont want mul

2. Database Connection

3. Configuration Manager

## Kha p singleton ki need nhi h:

Jha p hme pata h ki hme different instances of objects hi bnane h jaise multiplayer games in which different players will have different objects.
